Lexical Analyzer(Lexer)
This project implements a Lexical Analyzer (also known as a Scanner) as the first phase of a compiler. It processes source code and breaks it down into meaningful Tokens based on predefined grammatical rules.

🛠 How it Works
Input: A string of source code (e.g., int x = 10;).

Process: The scanner uses Regular Expressions (Regex) to match sequences of characters (Lexemes).

Output: A list of categorized tokens (e.g., KEYWORD, IDENTIFIER, OPERATOR).

🚀 Getting Started
Prerequisites:
Python 3.x installed on your system.

No external libraries are required (uses the built-in re module).

Running the Program:
Clone or download the lexer.py file.

Open your terminal or command prompt.

Run the script using:
python script.py
